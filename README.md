# Лаванда — магазин цветов

Вёрстка главной страницы цветочного магазина «Лаванда».

**Сайт:** https://krisratman.github.io/LavandaShop/

Сайт публикуется на GitHub Pages автоматически при каждом пуше в ветку `main` (см. [.github/workflows/pages.yml](.github/workflows/pages.yml)).

## Разработка

```bash
npm install
npm run dev    # пересборка CSS (Tailwind) при изменениях
npm run build  # минифицированная сборка CSS
```

Готовые файлы сайта лежат в папке `public/`.
